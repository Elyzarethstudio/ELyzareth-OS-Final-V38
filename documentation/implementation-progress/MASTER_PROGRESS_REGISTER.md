## 3. Canonical Status Definitions (Strict Enforcement)

- **`STRUCTURE_CREATED`:** Directory/package hierarchy exists on disk (`.gitkeep` + `OWNERSHIP_INDEX.md` where applicable). **Zero functional implementation claimed.**
- **`RECONCILED_EOS_STRUCT_UI_003`:** Structural ownership, duplicate-path removal, and route mapping settled and verified under `EOS-STRUCT-UI-003`.
- **`EXISTING BASELINE`:** Pre-existing code from the original `elyzareth-os.zip` baseline preserved on disk.
- **`NEW UNAPPROVED ADDITION`:** Code or UI added outside the `STRUCTURE ONLY` authorization; preserved on disk awaiting Student-Director quarantine/remediation authorization (`ARCH-DEC-03` / Phase 1).
- **`APPROVED ADDITION`:** Addition explicitly requested and approved by the Student-Director.
- **`DECISION REQUIRED`:** Blocked pending an explicit architectural or policy decision (`ARCH-DEC-03` through `ARCH-DEC-08`).
- **`NOT IMPLEMENTED`:** No approved functional implementation exists yet.
- **`ACCEPTED`:** Reserved exclusively for explicit Student-Director sign-off after runtime verification.
