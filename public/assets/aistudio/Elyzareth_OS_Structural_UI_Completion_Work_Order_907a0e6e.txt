======================================================================

A. Retain exactly the existing four Gradle modules for this phase:
   :app
   :core:foundation
   :core:kernel
   :core:shared

B. Do NOT create 14 separate Gradle feature modules.
   The target architecture explicitly recommends retaining the four-module
   topology during the current phases. Feature separation is by package,
   ownership and dependency boundaries inside the existing modules.

C. :app owns:
   - Application shell and navigation.
   - Compose UI screens and UI components.
   - ViewModels.
   - Room SQLite implementation and Android persistence adapters.

D. :core:foundation owns platform-independent constitutional/domain
   definitions and shared domain contracts.

E. :core:kernel owns the Sovereign Kernel implementation and its kernel
   interfaces/state machinery.

F. :core:shared owns shared supporting services, security/backup primitives
   and optional integration adapters, within the existing dependency rules.

G. Existing App 01 Lyric Generator, App 02 Corpus Curator and 3.2.1.0
   Protocol Console are preservation items. They must remain available and
   mapped into the unified application. Do not retire or replace them.
